전문가 검토지

● 저장되지 않은 수정이 있습니다
  • 선생님, 검수에 함께해 주셔서 감사드립니다. 아래는 검사 기록지와 같은 표입니다. 고치실 칸을 누르시면 바로 수정하실 수 있고, 고친 칸은 노란색으로 표시됩니다(마우스를 올리시면 AI 의 원래 값이 보입니다). 5. 의미유형은 해당하는 유형을 누르시면 들어가고 다시 누르시면 빠지며(바로 저장됩니다), 9. 문법 오류는 목록에서 골라 주세요(오류가 둘 이상이면 「조사누락/어미오류」처럼 묶인 항목). 4. 어절수와 10. 반응 지연시간은 숫자로 고치실 수 있고, 지연을 잴 수 없으면 「측정불가」로 적어 주세요.
  • 각 행 왼쪽의 ▶ 로 그 발화를 들으실 수 있습니다. 확인하신 행은 ☑ 해 주세요. 「이어서 재생」을 켜 두시면 행과 행 사이의 소리까지 끊김 없이 이어지고, 지금 들리는 행이 표시됩니다(위쪽에 「행 사이」가 보이면 기록되지 않은 구간입니다 — 빠진 발화가 있으면 비고에 적어 주세요). 끄시면 누르신 행만 듣고 멈춥니다.
  • 아이 발음이 표준과 다르면 표준어로 적고 실제 발음을 대괄호로 함께 적어 주세요(예: 「했어[해떠]」). 같은 말이 앞 행에 이미 나왔으면 처음 행에만 전사하시고, 뒤 행은 화자 칸에서 「중복」을 골라 주세요(분석에서 빠집니다).
  • 빠진 발화나 판단 근거 등 칸에 담기 어려운 내용은 맨 오른쪽 「비고」 칸에 덧붙여 주세요. 표 아래 ③·④·⑤에는 선생님의 확정값·평정·판정을 부탁드립니다.
  • 입력하신 내용은 자동으로 서버에 저장됩니다(화면 위 「서버 저장됨」 표시). 오른쪽 위 「저장」(⌘S / Ctrl+S)을 누르시면 바로 저장됩니다. 다른 컴퓨터에서도 같은 비밀번호와 같은 성함으로 여시면 이어서 하실 수 있습니다. 저장되지 않은 수정이 있으면 빨간 표시가 나오고, 창을 닫으실 때 확인 창이 뜹니다.
  • 작업 시간은 화면 위와 맨 아래 「작업 시간 기록」에 보입니다. 이 창이 선택된 상태에서 2분 안에 조작하셨거나 음성이 재생 중인 시간만 세고, 30초마다 서버 시각으로 기록합니다. 선생님과 저희가 같은 기록을 봅니다. 검토 내용과 작업 시간은 입력하신 성함별로 따로 저장되니, 다음에도 같은 성함으로 열어 주세요(띄어쓰기는 자동으로 맞춥니다).
